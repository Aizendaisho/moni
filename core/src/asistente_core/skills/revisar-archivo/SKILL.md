---
name: revisar-archivo
title: Revisar un archivo
description: Revisar UN archivo concreto (un documento, una descarga, un programa o un zip) para ver si es peligroso o tiene virus.
examples:
  - ¿este archivo tiene virus?
  - revisa si factura.pdf es seguro
  - me llegó un documento de Word por correo, ¿lo puedo abrir?
  - analiza el archivo que descargué
  - ¿es peligroso este exe?
  - escanea este documento
  - ¿ese zip es confiable?
  - mira si este archivo es malware
---
1. Llama a revisar_archivo con el nombre o la ruta que dijo el usuario, tal cual. Si no dijo
   cuál archivo, pregúntale el nombre antes de nada.
2. Si la herramienta no lo encuentra o hay varios, dile las opciones que te dio y pregunta.
3. Responde empezando por el veredicto en palabras simples:
   - peligroso: "No lo abras." y explica los motivos de gravedad alta.
   - sospechoso: "Mejor no lo abras todavía." y explica los motivos.
   - sin hallazgos: "No encontré nada raro", y aclara que eso no es una garantía total.
4. Si en los datos aparece "Descargado de", dilo; si no aparece, no digas de dónde viene.
   Menciona si Windows Defender lo revisó.
5. Cuenta solo lo que dice el resultado. No inventes nombres de virus, carpetas ni detalles.
6. Nunca abras ni ejecutes el archivo. Si es peligroso, recomienda borrarlo o no abrirlo; tú
   todavía no puedes borrarlo ni ponerlo en cuarentena.
