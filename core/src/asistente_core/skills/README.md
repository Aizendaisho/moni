# Skills de Moni

Cada carpeta es una skill: un `SKILL.md` con los pasos de una tarea. Antes de cada mensaje, el
núcleo compara el mensaje con los `examples` de cada skill y, si una encaja, le pasa los pasos
al modelo. Para crear las tuyas, copia una carpeta a `data/skills/` y edítala: no hace falta
reiniciar Moni. Si usa el mismo `name` que una de aquí, la tuya la reemplaza.

Consejos para que funcionen bien con un modelo pequeño:
- 5 a 10 `examples` variados, escritos como los diría una persona.
- Pasos cortos y numerados, nombrando las herramientas exactas.
- Decir qué NO hacer (inventar, prometer lo que no puede).
